# Sicurezza di Eurise / Eurise security

## Segnalare una falla
Se trovi una falla di sicurezza o di privacy in una qualsiasi parte della suite (app Android, Ponte, estensione per
Firefox, pacchetti per il computer, flussi di compilazione), **non aprire una issue pubblica**.

- Usa la segnalazione privata di GitHub: scheda **Security → Report a vulnerability** di questo repository.
- Scrivi cosa hai trovato, su quale app e versione (o giro di compilazione), come riprodurlo e cosa può fare chi la sfrutta.

Rispondiamo entro **3 giorni lavorativi**; una falla grave si corregge entro **14 giorni**, le altre entro 90. Ti
teniamo informato e, se vuoi, ti ringraziamo per nome nelle note della correzione. Chi cerca falle in buona fede, senza
toccare dati di altri e senza interrompere i servizi, non ha nulla da temere da noi.

## Reporting a vulnerability (English)
Please do **not** open a public issue. Use GitHub's private reporting (**Security → Report a vulnerability**) with the
affected app and version, steps to reproduce and impact. We answer within 3 business days and fix critical issues within
14 days (others within 90). Good-faith research that does not touch other people's data is welcome.

## Cosa copre
Tutte le app della suite (Eurise, Password, Browser, Galleria, Posta, Messaggi, Telefono, Chat, Leggi, Voce, AI, Office,
Mappe, Tastiera), il Ponte sul telefono e sul computer, l'estensione per Firefox, il Flatpak e i flussi di GitHub Actions.
Le librerie di altri (GeckoView, LibreOffice, Organic Maps, HeliBoard…) vanno segnalate anche ai loro autori.
